Original geometric test fonts, CC0-1.0 (see LICENSE).
No system fonts, upstream outlines or downloaded artwork are used.

Reproduction:
  Python 3 with fonttools==4.60.1
  python3 tools/generate_typography_fonts.py
The generator pins OpenType timestamps and removes its project-local masters.
FontTools is MIT-licensed; no FontTools source is embedded in these fonts.

All use 1000 units/em, ascent 800, descent -200, with rectangular test outlines.
Geometry Variable has wght 100/400/900: widths 300/500/800, advances 400/600/900.
It contains real gvar/HVAR data, not three static faces.
Geometry CFF2 has a real CFF2 blend and variation store: width 500 at weight
400, width 800 at weight 900; advance remains 600 by design.
Geometry Color uses COLR v0 layers and CPAL red and half-alpha blue. Its GSUB
maps family ZWJ, US regional flag and skin modifier sequences to single glyphs.
Geometry Bitmap has an actual 20ppem sbix PNG strike: 10x14 red/purple pixels,
no CSS image substitution. The PNG is generated solely with Python's stdlib.

The fonts intentionally provide tiny test coverage, not usable typefaces.
Independent reftest rectangles derive from these documented design units,
not screenshots produced by the engine.
